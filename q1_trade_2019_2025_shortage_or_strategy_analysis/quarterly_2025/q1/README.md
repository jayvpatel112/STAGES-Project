# Q1 2025 German Electricity System — Detailed Marimo Analysis

This is a local Marimo notebook project for a detailed first-quarter analysis of Germany's electricity generation, demand, residual load, and optional weather context.

The project is intentionally written as an analysis notebook first. The report section should be written only after the notebook has been run, the data quality checks have been reviewed, and the generated figures/numbers have been accepted.

## Project structure

```text
q1_2025_detailed_marimo_project/
├── q1_2025_detailed_analysis.py
├── requirements.txt
├── README.md
├── src/
│   ├── smard_client.py
│   ├── energy_analysis.py
│   ├── plotting.py
│   ├── weather_client.py
│   └── weather_analysis.py
├── data/
│   ├── raw/
│   └── processed/
├── figures/
└── reports/
```

## How to run

Open Anaconda Prompt or a terminal, then run:

```bash
cd analyses/quarterly_2025/q1
pip install -r requirements.txt
python -m marimo edit q1_2025_detailed_analysis.py
```

Run the notebook from top to bottom.

## Data sources

- SMARD/Bundesnetzagentur chart data API for hourly German electricity generation and load.
- Optional Bright Sky API for DWD-based weather observations from representative German locations.

No synthetic electricity data is used. Cached API responses are stored under `data/raw/`.

## Main generated outputs

Figures are saved under `figures/` and tables/text summaries under `reports/`.

Important output files include:

- `reports/q1_2025_report_numbers.txt`
- `reports/q1_2025_headline_metrics.csv`
- `reports/q1_2025_source_totals.csv`
- `reports/q1_2025_monthly_summary.csv`
- `reports/q1_2025_worst_residual_load_hours.csv`
- `reports/q1_2025_best_renewable_hours.csv`

The notebook should be used to understand the quarter first. Only then should the report section be written from the real outputs.

The downloaded data, generated figures, and generated reports are intentionally
ignored by Git. The directory placeholders remain in the repository, while every
output can be regenerated by running the notebook.
